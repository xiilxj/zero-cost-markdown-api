# Zero Cost Web to Markdown API

一个免费、零成本的网页内容抓取并转换为 Markdown 格式的 API 服务。非常适合 LLM/GPT 上下文灌入和知识库构建。

## 功能特点
- 网页降噪，去除页头、页脚、广告与导航栏。
- 自动检测网页编码，完美支持中文。
- 一键转换为格式规范的 Markdown。

## 部署于 Hugging Face
本仓库已配置好适用于 Hugging Face Spaces Docker 环境的 `Dockerfile` 和元数据。
